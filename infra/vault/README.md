# Vault (dev mode only)

Dev-mode Vault only (`-dev` flag); no production HA/KMS configuration here per Requirement 18.5.

This directory is a placeholder for development-only Vault assets. Production HA
topology, KMS auto-unseal, and real mTLS material are explicitly **out of scope**
for the multi-service-scaffold spec (see `requirements.md` Requirement 18.5) and
will be addressed in a future ops/security spec.
